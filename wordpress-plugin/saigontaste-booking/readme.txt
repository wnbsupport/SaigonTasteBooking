=== Saigon Taste Booking ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0

Booking form for restaurants managed in the Saigon Taste Booking app.

== Setup ==
1. Upload and activate the plugin.
2. Settings → Saigon Taste Booking: enter the app address and the restaurant's connection key (from the app: Restaurants → Website connection → New key). Click "Test connection".
3. Add the shortcode [saigontaste_booking] to the booking page.

Optional shortcode attributes: accent="#24305a" title="Book a table".
